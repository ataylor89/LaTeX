# How did LaTeX get its name?

## Long answer

How did LaTeX get its name?

This is a really good question.

I believe that the "La" in LaTeX refers to the first two letters of Leslie Lamport's last name.

In other words, the "La" in LaTeX refers to the creator of LaTeX, Leslie Lamport.

The "TeX" in LaTeX refer to the Greek letters tau, epsilon, and chi.

(Keep in mind that the Greek letter chi looks like an X.)

The Greek letters tau, epsilon, and chi are found in the Greek word τέχνη, which means craft, skill, or art.

So you can see that "TeX" is also a reference to the Greek word τέχνη.

TeX is actually the name of a typesetting language created by Donald Knuth.

Leslie Lamport built LaTeX on top of TeX.

LaTeX is kind of like an extension of TeX, because it adds a new collection of macros to TeX, which makes it easier to use.

So the "TeX" in LaTeX is also a reference to the typesetting language that Donald Knuth created, on which LaTeX is based.

## Short answer

The "La" in LaTeX is a reference to the creator of LaTeX, Leslie Lamport.

The "TeX" in LaTeX is a reference to the TeX typesetting language, that Donald Knuth created, on which LaTeX is based.

The "TeX" in the TeX typesetting language is actually a reference to the Greek letters tau, epsilon, and chi, because they are the first three letters in the Greek word τέχνη, which means craft, skill, or art.

## Pronunciation

Any pronunciation of LaTeX is fine - "lah-tech", "lay-tex", et cetera.

But I think that it's meant to be pronounced "lah-tech", after the Greek word τέχνη, which is pronounced "tech-nay".
